# ERP System

Single repository for the ERP system.

- `backend/`: ASP.NET Core (.NET 10), Clean Architecture (Api, Application, Domain, Infrastructure) plus xUnit tests.
- `frontend/`: React 19 + Vite + Tailwind, Arabic RTL interface.

Each part keeps its own README with setup and run steps.

Both original repositories were merged with their full commit history:
`DEV-Squad-Solutions/ERP_SYSTEM` (backend) and `DEV-Squad-Solutions/ERP-SYSTEM_FRONTENDTEAM` (frontend).
