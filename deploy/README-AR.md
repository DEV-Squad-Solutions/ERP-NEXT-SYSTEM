# تثبيت وتحديث ERP على السيرفر (بدون إنترنت)

ملف واحد تضغط عليه: **install-or-update.bat**. بيعرف لوحده تثبيت جديد ولا تحديث.

## على جهاز التطوير (فيه إنترنت و Docker)
1. `git pull` عشان تبني من آخر main.
2. من فولدر deploy:
   `powershell -ExecutionPolicy Bypass -File .\build-images.ps1 -Version 2.1`
   (غيّر رقم الإصدار كل مرة). بيطلع ملف `erp-images-2.1.tar` جوه deploy.
3. انسخ فولدر **deploy كله** على الفلاشة.

## على السيرفر (192.168.1.5)
1. انسخ الفولدر من الفلاشة لمكان ثابت، مثلا `C:\ERP\deploy`.
2. لو أول مرة: انسخ `.env.example` باسم `.env` واملا `SQL_SA_PASSWORD` و `JWT_SIGNING_KEY`.
   لو عندك `.env` قديم شغال: حطه في نفس الفولدر زي ما هو (نفس الباسورد ونفس مفتاح JWT، متغيّرهمش).
3. تأكد إن Docker Desktop شغال.
4. دبل كليك على **install-or-update.bat**.
5. استنى لحد ما تشوف `OK تم بنجاح`. افتح `http://localhost`.

## السكربت بيعمل إيه بالترتيب
- يفحص Docker وملف `.env` (ويرفض لو `SEED_ENABLED` مش false).
- يقرر: لو فيه `erp-db` أو volume اسمه `erp_sql_data` يبقى **تحديث**، غير كده **تثبيت جديد**.
- لو لقى volume قاعدة بيانات بإسم تاني، بيقف ومبيكملش (عشان ميعملش قاعدة فاضية بالغلط).
- في التحديث: **نسخة احتياطية الأول** في `C:\ERP_backup`. لو فشلت أو مش سليمة، بيقف ومفيش حاجة بتتغيّر.
- يحمّل الصور من `erp-images-*.tar`، ويشغّل الـ API والواجهة بس (قاعدة البيانات مش بتتلمس في التحديث).
- الـ API بيطبّق تعديلات القاعدة (migrations) لوحده وهو بيشتغل. تعديلات إضافية بس.
- يستنى `http://localhost:8080/health/ready` لحد 5 دقايق ويطبع نجاح أو فشل مع آخر سطور السجل.

## أمان
- السكربت مفيهوش `down` ولا `-v` ولا حذف volume. الداتا في volume `sql_data` ومبتتحذفش.
- **ممنوع** تكتب بنفسك: `docker compose down -v` أو `docker volume rm` أو `docker system prune --volumes`.
- أي خطأ = توقف برسالة واضحة، والبيانات زي ما هي.
- نسخة احتياطية يدوية في أي وقت: `powershell -ExecutionPolicy Bypass -File .\backup.ps1`
- الرجوع لنسخة: ابعت لي الأول، متعملش restore لوحدك.

## ملاحظة صراحة
السكربتات دي مكتوبة بس ومتراجعة، لكن **متجربتش على Docker حقيقي** قبل أول تشغيل ليك. شغّلها أول مرة وانت واقف عليها، وابعت أي رسالة خطأ كما هي.
